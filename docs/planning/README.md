# 阶段规划与施工管理

本目录维护 WEX PC 端 的阶段目标、工程依赖、施工批次安排和阶段验收门槛。

| 文档 | 用途 |
|---|---|
| [阶段路线图](PHASE-ROADMAP-2026-10-31.md) | 定义产品阶段、首版目标、后置范围和阶段完成条件 |
| [后续施工计划](CONSTRUCTION-PLAN-2026-10-31.md) | 定义第八批起的模块施工顺序、依赖、交付和验收 |
| [当前任务书](../batch8/PLAN.md) | 下一批可直接执行的具体范围 |

维护规则：

- 阶段路线图控制长期目标和阶段门槛，不取代正式产品基线。
- 施工计划控制模块批次顺序，不代替模块自身的业务契约。
- 每个施工批次的具体任务书、执行记录、测试原始证据和验收报告保存在对应 `docs/batchN/`。
- 完成批次后更新施工计划状态和索引；不覆盖历史报告。
- 用户待决事项、权限政策和产品范围不得由施工计划自动批准。
