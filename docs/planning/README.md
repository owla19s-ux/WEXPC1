# 阶段规划与施工管理

本目录保存 WEX PC 端的阶段规划材料。规划文档必须区分产品范围、工程阶段、模块施工批次和独立验收，不得将它们混为一张表。

## 当前状态

- 第八批已完成，交付证据见 [第八批报告](../batch8/REPORT.md)；[第八批任务书](../batch8/PLAN.md)仅保留历史范围。
- 现有[阶段路线图](PHASE-ROADMAP-2026-10-31.md)和[后续施工计划](CONSTRUCTION-PLAN-2026-10-31.md)是此前形成的规划材料，保留用于回顾和对冲，不直接作为新阶段的当前派工依据。
- [G1–G7 基础能力落地映射](FOUNDATION-CAPABILITY-IMPLEMENTATION-MAP-2026-10-31.md)说明能力归属和跨模块验收要求，不等于产品完整功能表或 0.1.1 版本范围。
- **当前尚无新版本确认后的正式阶段任务总表/施工卡汇总入口。**

## 后续规划建立顺序

1. 产品功能表：按模块整理完整功能、边界、依赖和当前实现状态。
2. 0.1.1 版本计划：从产品功能表中确认首版纳入范围、依赖、阶段门槛和验收目标。
3. 阶段任务总表：将确认后的版本范围拆成阶段、模块施工单元和依赖关系。
4. 独立施工卡：每项具体施工任务有明确范围、前置资料、修改边界、测试和验收条件。

## 文档归属规则

- 阶段规划维护阶段目标、范围、依赖与门槛；模块业务语义仍以各模块 `CONTRACT.md` 为准。
- 施工卡保存单项任务的可执行要求；执行回执记录实际修改、提交和测试证据；独立验收记录由独立验收者给出。
- 完成的任务书、回执、原始测试证据和验收报告保留历史，不覆盖或改写成当前状态。
- 用户待决事项、权限政策和产品范围不得由施工计划或执行 AI 自动批准。
