## 2. 功能树与归属矩阵

每行是功能族，分号列出下级功能；不是一个新增子系统或一个施工批次。

## 3. 功能依赖与模块验收

1. app 的装配、数据定位与领域加载支撑其他功能；单个工作区失联只禁用受影响能力。普通对话不依赖 Space、模板、Task 或 React Flow。
2. API 对话依赖有效连接和资料发送授权；AI 配置只引用连接。Space 关联对象不要求执行能力存在，不隐含读取与授权。
3. 任务运行依赖工作定义版本、实际执行者/连接就绪、有效授权和资源协调；不依赖所有专业视图完成。React Flow 编辑原型通过不能证明运行链路通过。
4. 外部结果、操作回执落盘、产物验证和任务验收分别成立；连接器报告不能直接写最终任务结论。恢复依赖证据，不依赖重新发送原提示。
5. 备份覆盖公共数据与另行选择的 Space/Context 及所需产物，不能只拷一个根目录宣称完整；凭证、有效许可和外部系统文件各有边界。

后续施工验收按模块列公开能力、输入前提、状态权威、失败/未知/取消语义、修改局部性及模块测试。组合验收再检查安装至任务接续的真实行为，**不把该行为顺序变成跨域串改的链路施工单位**。
