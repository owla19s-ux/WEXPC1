## 决策状态约定

- **A**：已确认的架构约束。
- **B**：研究推荐或候选方案，未自动获得批准。
- **C**：需要隔离实验或真实环境验证。
- **D**：需要用户作出的产品方向、权限或政策决定。

实验通过只能更新对应的 C 类证据，不能自动把 B 升级为 A；AI 或执行者不得替用户关闭 D 类事项。最新批次的集中状态见 [第六批决策记录](../batch6/DECISIONS.md)。
