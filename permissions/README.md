# permissions — WEX 权限系统

状态：2026-10-30 预留独立顶层目录，职责已明确，规则与代码尚未实现。

负责用户/角色/模块/Context 相关授权策略、权限判断与撤权；保留既有“三层权限”（模块启用、全局访问、对话启用）的设计依据，后续可按真实需求细化。角色身份、角色配置由 `AI/` 维护；**权限授予和有效权限由此处决定**，不能因为角色提示词声称具备权限就授权操作。

`plugins/` 管理模块是否装载及服务注册，不代替权限系统；`connections/` 执行外部调用但不能自行决定绕过权限；`shared/credentials/` 仅处理秘密存储，不负责授权策略。实际操作必须经受控调用边界检查，并记录必要审计与回执。

当前不预设完整 RBAC/ABAC 实现、账号身份模型和多租户权限。用户账号体系由 `accounts/` 研究，两者通过显式接口关联，不能混为同一套业务。
