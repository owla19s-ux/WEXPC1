# permissions — 策略、授权决定与撤权

**当前：第七批基础产品实现已落地；稳定实现与限制见本文“第七批实际实现”及[验收报告](../docs/batch7/REPORT.md)。下方阶段描述保留为历史依据。**
历史初始状态（第二批）：当时尚无产品授权引擎；第七批已实现本域基础授权服务。此处仍是唯一的权限业务域；[shared/permissions](../shared/permissions/README.md) 仅保留旧入口指引，不再承担另一套授权服务。

## 判断什么

用户的明确授权、当前执行主体与入口、适用职责、Context/任务范围、目标资源及动作共同约束请求。保留“模块启用 / 全局访问 / 对话启用”三层依据；独立聊天/非对话任务也必须具有适用于自身入口的范围，不能伪造一个对话标识绕过检查。非对话入口如何对应既有范围，留给业务契约细化。

组织关系不产生授权：多个 Space 引用同一 Context、角色跨 Context 兼任、任务分配、工具可发现、模板启用、同一个模型或外部账号，都不能自动扩权。职责描述与授权分别维护，不按角色名称设超级管理员。不存在隐含跨入口权限并集。

## 谁负责检查与记录

- `permissions` 维护策略、授权/审批/撤销事实及判定依据；不持有角色定义、任务真相或凭证秘密。
- `connections` 的宿主受控调用边界调用此域检查对外请求和外部回调，关联判定依据与操作回执；具体连接器不能自行批准或修改授权记录。
- 内部领域正式入口保护自身写入规则与适用授权；普通内部调用不必全绕连接层。外部能力已过准入仍不允许绕过目标领域的修订/范围检查。
- 真实资源/进程执行边界落实可兑现的限制；排队前判断不能代替执行前复核。撤权后阻止新的数据提供与调用，处置在途工作的责任由执行方承担，工作流记录其后果。
- 授权记录与操作记录分别归本域与 `connections`，通过可追溯引用/当时依据关联，不复制第二套可修改的权限账本。具体持久化格式、求值算法和审计接口未定。

## 外部执行与安全极限

[app](../app/README.md) 负责受信任装配与可用的进程隔离；外部 Agent 受其实际 OS/服务权限约束。WEX 不提供 Key/文件就能控制后续 WEX 出口，但不能据此保证已有广权限的外部 Agent 被限制。无法约束的权限要显式暴露，不能声称“任务范围就是系统沙箱”。

第三方插件不能直接进入 Electron 主进程；独立进程本身也不是完整安全沙箱。插件/Agent 的返回文本是外部输入，不是授权或验收命令。停止本地等待、取消请求、撤权、外部已停止和副作用已回滚分别记录；不承诺模型遗忘或远端数据删除。

账号域 `accounts` 仍预留，不将远端登录作为本地授权前置；凭证保管归 `shared/credentials`。本批不设计完整账号平台、RBAC/ABAC 或插件沙箱。

待实验：Windows 实际权限收敛、外部凭证/环境传递、撤权竞态、插件回调身份与重放防护、跨进程终止及残留进程。场景 S7 的业务拒绝已有替身测试，未证明 OS 隔离。

## 第七批实际实现（2026-10-31）

当前公开入口 `permissions/src/index.ts`，消费者 `app/src/foundations.ts`；仅导入 shared 公开的 Store/Json/结果类型，不读取任何其他业务私库。

`createPermissions(Store, TrustPort)` 提供 evaluate / recheck / grant / revoke / history。TrustPort 只能由可信宿主实现：current 将真实调用对象绑定为核验事实，canManage 核验精确管理请求，canReadHistory 仅用于本批受信任完整历史管理入口。外部文本、Renderer字段、Key、角色和Context自报值不实现该端口。当前无IPC/OS主体认证实现，正例事实为测试宿主注入；CLI默认全部无可信事实/无管理权。

许可按 subject、entry、conversation、可空context、resource、action、target、relationship及relationshipGeneration精确匹配；对话三层开关与来源限制任一不满足均不能允许。非对话返回 entry_policy_unresolved，不伪造对话、自动降级或跨Context发布策略。

每次授权/撤销以聚合修订CAS持久化，记录命令/原意图/精确范围/代次；撤销保留历史，重新授予必须新事实。recheck 重新读取当前授权，并核对旧决定的范围/修订/代次；旧允许、迟到旧修订和重新授予前的旧决定均不能继续使用。保守地使任一授权变更失效旧决定；当前无按资源细粒度代次优化。

提交三态原样交给调用方；重复意图核对原命令并query原提交，unknown不自动再写。失败/损坏/存储不可用返回不可判定或unknown，不放行。history当前只向受信任管理入口提供完整本域历史；普通用户按资源筛选、分页与可见性投影尚未开放，不可将布尔管理检查当成任意用户读取许可。

出口前接口是复核点，不是外部副作用的原子锁；复核与真实资源/网络发送间竞态、IPC重放、Windows主体与安装关系识别仍C。未实现有限次数、自动审批、D01非对话政策、D05强审计全局阻断或D06降级发布政策。

测试：`npm run test:permissions`。真实SQLite/共享存储替身共用本域行为；`permissions/tests/reader-contract.mjs` 被app消费者对真实权限与权限替身共同执行。历史是本域事实，不复制Operation或Task账本。

## G3：非对话入口施工门槛

当前真实实现对 Conversation 入口有允许路径；Task、用户直接操作和外部回调等非对话入口仍按 `entry_policy_unresolved` 阻断。不得伪造 Conversation ID、继承创建 Task 的对话授权，或把角色/Context/连接可用性当成许可。对应入口的可信主体、实例/代次、目标和动作策略经批准、实现并由真实消费者验证前，不开放副作用。

G1 引用、G2 工具意图、G4 Operation 历史和 G5 搜索命中均不产生授权。详见[基础能力落地映射](../docs/planning/FOUNDATION-CAPABILITY-IMPLEMENTATION-MAP-2026-10-31.md)。
