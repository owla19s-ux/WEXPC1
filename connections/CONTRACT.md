# connections 业务契约（第四批设计草案）

基线：`owla19s-ux/WEXPC1@a62996af9863e60b15e4513389c7654719907920`。仅设计，未实现、未重跑实验，不冻结函数、状态枚举、数据库 schema、IPC、wire 或插件包协议。下列 C01 等仅为文档定位符。适用 L03/L05/L06/L09/L11；链路用于组合验收，施工单位仍为本模块。

标记：**A 已定**为既有用户确认/职责边界；**B 推荐未批**为本文具体行为建议；**C 待实验**为须运行取证的假设；**D 重大决策**为尚需确认的产品/权限取舍。A 不表示产品已实现。本文不是把来源研究报告中的取证 A/B/C 等级重新命名。

## 1. Owner、范围及事实

**A** connections 宿主边界唯一维护 Operation 的意图依据、单次派发尝试、外部观察与回执；具体适配器报告事实，不自行写操作账本。workflows 唯一维护 Task、工作轮次、流程进展和验收，只引用 Operation；conversations 维护消息与逻辑生成。三个对象不能共用一个“完成”状态。外部系统拥有实际文件、提交、远端对象及其状态；回执保存成功不能证明外部动作成功。

本模块拥有连接配置与能力可用性；秘密值归 shared/credentials，授权决定归 permissions，工作资源占用协调归 workflows/runtime。内置 API/GitHub/local 与外部 Agent 均可由可信 app 装配；不需要 WEX 插件、Cordis 或 `dsh/` 宿主作为前置。普通领域内部调用不强制经过公共连接层，跨边界外发/回调遵守受控入口。

**A** Context 可空，Task 可空。宿主必须为每次调用建立可信主体、实际入口和本次动作/目标范围；Context、角色、任务名、外部 sessionId、连接配置名都是资料，不是身份凭证。无 Task 的普通副作用同样检查冲突资源及未知占用；通过宿主按需注入 runtime 资源协调能力，不制造 Task/流程实例。若动作需协调而能力未装配，**B** 应报告不可用并不派发，不能悄悄退化为无协调。

## 2. 公开能力及可断言行为（B，A 边界继续适用）

### C01 连接配置与能力发现

提供给 AI 配置、conversations、workflows、获准配置 UI 和装配根；读取/调整连接位置、Provider 或外部实例引用、已验证版本及支持能力。凭证只存引用；消费者得到其可见的能力描述、可用性、限制与验证时间，不得获得秘密或未授权实例目录。

前提：宿主认证主体；配置写入与探测分别判权，探测若实际联网/启动进程是独立 Operation。Context 可空；发现不授予执行权限。配置修订采用预期基线，过期修改拒绝并给可见冲突；在途尝试绑定原配置/适配版本，改配置不重定向已派发动作。禁用连接阻止后续动作，不代表终止在途工作。

权威：配置由本域保存；“在线”仅为有时效的观察，能力不存在、不可用、无权限和未核实分别表达。发现失败不伪造空能力等于服务确实不支持；超时保留最近证据时间且不可当新成功。重复探测可合并等价读取，但不得合并不同主体权限视图。

断言：DSH headless 描述可以 submit/observe，不因同一上游存在 ACP 就显示已实现 interrupt；未授权连接不返回其密钥标识细节；改连接修订 r2 后 r1 调用仍指向原实例。配置通知只提示版本失效，消费者重新查询获准投影。

### C02 准入、资源解析与单次派发

提供给工作流、对话、获准 UI 及反向调用装配入口。消费可信身份、permissions 当前判定、适配器资源解析、shared 存储、按需注入的 runtime 协调与最小领域回调。

前提：明确动作、目标和输入依据；宿主校验大小/路径/URL/可用能力，区分读取与副作用；先建立主体范围并检查，排队后实际派发前复核当前权限和适用资源版本。适配器提供真实 backend、路径/对象/会话定位及访问方式；资源身份无法判定而可能冲突时保持阻塞/诊断，不用 Context ID 代替资源身份。只有 permissions 明确允许才能取数/派发；需要审批、不可判定、拒绝、判权超时或断连均为零动作，不把未收到拒绝当允许。已授权不意味着 OS 或远端实际允许。

协调入口：W03 只作计划预检，不另取得执行占用。C02 在实际派发前经宿主调用 W05，以同一 Operation 意图、规范化资源依据与适用修订获取或复核同一协调引用；不得由工作流与连接边界各占一次造成自锁。重送关联原引用，异意图/异资源不得冒用。协调回复须能表达请求/持有/未决冲突/释放是否成立、依据修订及证据，不能仅返回布尔允许；未知或修订不适用时不派发。资源身份及释放裁决归 W05，本域只保存引用与观察，不自行清除未知占用。

权威写入：宿主先保存尝试依据，再开始外部派发；明确未提交或提交确认未知均不开始外发；后者先按原意图读回，不能断言记录未写。派发后只追加本次观察/结果，不反写 Task。**C** 已持久意图与外部派发间崩溃仍可歧义，不能因本地缺确认推断未执行。操作结果保存失败返回保存故障与已观察证据，不能把成功观察改称“外部失败”或自动再执行。

拒绝：权限拒绝、前置版本冲突、连接不支持、资源冲突均不派发并区分原因；远端明确拒绝是外部失败观察；启动前可证明未执行的错误与派发后异常区分。timeout 是等待期限，disconnected 是通信事实，unknown 是无法确定结果；它们可同时存在，不能压成同一失败。只有证据支持才断言无副作用。

取消/重试：去重在提供方声明的有限作用域与保留窗口内成立，作用域至少绑定可信主体/入口、能力和意图；同意图同规范化 payload 返回原关联，不重复派发，同意图异 payload 必须拒绝，不能新建 attempt 绕过。窗口、跨重启保留和查询能力须在实现契约声明/证明；窗口外不能承诺去重，历史未知也不能因窗口到期当作新请求重发。仅在远端明确支持且幂等范围/有效期/请求一致性均成立时利用其幂等能力；本地去重不能保证外部恰好一次。unknown 不自动重试；只有已满足安全重试前提的同一意图可产生经允许的新 attempt；新的不同意图必须显式说明且不得用来绕过原未决副作用。所有新尝试重新判权、复核原协调关联并引用原尝试及恢复依据。

断言：无 Task 的本地文件写入遇到同一真实目录未知占用，外部调用为 0；attempt 保存失败调用为 0；外部已修改文件、result 保存失败时返回 observed 与未知，后续相同意图不重复写入；Task 的 r1 轮次仅存 Operation 引用；同意图异 payload 拒绝且 attempt 数不增；W03 预检后 C02 复核同一协调引用不自锁，失效则零派发；判权需要审批/不可判定/超时均零动作。

### C03 观察、查询与诊断

提供给 Operation 原调用者、runtime、conversations 和获准诊断页。宿主对读取 Operation、外部查询及敏感诊断分别判权；Task/Context 可空，凭持有操作 ID 不能越权。读取本地观察与主动查询外部是不同能力，后者须适配器实际支持。

宿主维护已保存的尝试/观察；连接器带上原尝试关联、来源版本、外部定位、顺序或可用游标与观察时间。乱序、重复、缺口和相互矛盾的结果保留出处，不能按最后到达覆盖；适配器解析失败保留受限原始证据/摘要与诊断，不在日志泄露 Key 或任务秘密。进度文本不等于外部状态确认，completed 不等于产物清单可信。

断连后本地查询仍可返回“截至某时已知”，主动查询不支持时明确返回能力限制，不能冒充历史恢复或活跃附着。只读查询可按有界策略重试；必须说明证据新鲜度。读取超时不更改原 Operation 的执行结论；查询外部返回 not found 也不自动证明未执行，需结合服务保留策略。

断言：原尝试 a1 的晚到 completed 保存于 a1，a2 不被覆盖；消费者错过通知后可查询补齐可见记录；DSH rc.5 的 final.text 为空而 turn_end 含 MISSING_CREDENTIAL，输出 failed 及原因，不据 final 或 exit 0 单独判成功。结果通知为失效/新证据提示，不作为独立真相或保证恰好一次送达。

### C04 请求停止、恢复线索与控制差异

提供给有控制权限的原调用者/runtime。取消、detach、close、中断 in-flight 请求和补偿分别声明；只对适配器已核实能力开放。请求目标须绑定外部实例、会话、尝试/执行世代，防止晚到取消误停新工作。取消本身判权且留可追溯控制依据。

宿主记录“已请求”“执行方确认停止”“无法确认”和已知副作用；适配器不写任务 cancelled。取消调用超时/断连保留未知；本地停止等候不等于外部停止，杀进程不等于后代全部停止，停止不等于回滚。重复取消可返回同一控制证据，不因重复请求再次发起工作；恢复历史、查询状态、继续旧会话、重派任务分开判权与记证。

恢复仅返回可获得的外部定位/状态/版本，不作业务重试裁决。cwd、preset、backend、版本或外部身份不匹配时拒绝续接，不回退新 session 冒充恢复。断言：不支持取消的 headless 路线明确报告限制，runtime 保持未决；Hermes CLI EOF 若仅 detach，不能标已停止；恢复不存在会话不自动 submit。

### C05 外部反向调用与最小领域能力交换

提供给装配后获准的外部请求来源；消费宿主身份映射及注入的窄领域能力。每次回调建立可信来源、原调用关联、目标动作和范围；外部自报 Context/Task 不能成为身份。回调 Context 可空；其目标数据由原 owner 过滤，连接器不获得整个宿主对象、数据库、Context 对象或权限账本。

读取任务文本只能读本次允许的任务，且每次重新判权；写领域对象最终由领域入口保护修订与不变量。回调是独立能力使用，必要 Operation 依据及结果由宿主记证；领域业务写入仍由领域 owner 完成。撤权阻止后续取数，已交出数据不能收回。**C** 跨进程来源认证、抗重放/撤权竞争方式尚待实验，不能把实验 readTask/Object.freeze 当产品安全保证。

断言：a1 对 t1 的授权不能用于读 t2；排队后撤权则回调不输出文本；重放同一副作用回调按原意图定位，不第二次变更目标；保存故障不使外部自动补偿或重放领域写入。

## 3. 具体适配职责与差异

以下是能力归属与验收约束，非要求每类都实现所有能力或创建 external 插件目录。

| 路线 | 适配器负责及资源证据 | 可验收的能力差异/限制 | 独立验收重点 |
|---|---|---|---|
| api | Provider 鉴权协议、模型请求、流式解析、限流/错误映射；记录实例/模型/请求定位，秘密取用经 credentials | 首版方向为多 Provider 原生 API；模型工具意图是下一次受控请求；流式中断不保证远端推理/计费停止 | 分块边界/重复片段/不完整结尾；401/429/服务失败；输出工具意图不调用工具；换 Provider 不改变任务范围 |
| github | 仓库/对象定位、GitHub 实际操作和服务专属诊断；保留 repo、ref/commit 与远端变更证据 | 当前仅职责说明；读取与创建/更新权限分开；不能预设所有写操作有幂等键或取消 | stale ref 不静默覆盖；创建响应丢失先查对象；查询无权不泄露私库；本批不承诺产品实现 |
| local | 本批先验授权文件/目录读写；真实路径/别名、文件版本/内容观察；终端/Git/编译范围仍待实测 | 真实资源在原位；权限/协调均不等于全局文件锁；外部未纳管进程可能并发变更 | 路径逃逸/别名同资源；写前版本变化；中文路径及 Windows 锁待验；读写文件不能自动扩大为 shell 能力 |
| 外部 Agent（DSH 优先） | 协议、进程/会话关联、backend+cwd、外部版本及可获得产物线索 | submit/observe/resume/query/interrupt/close 各自可选；Agent 独立权限和循环不归 WEX；不统一 wire | completed 后独立 diff/版本核验；断连未知；恢复不冒充附着；不引用 `dsh/` 加载器作为连接前置 |

DSH headless 既有实验锁 npm `0.2.1-rc.5`、源码 `ce7073d51254c26cd63b22a60835b8f948deb447`，二者 final 形态有差异。SDK/ACP 研究锁 `f3803c9…`：SDK 无 per-session close/prompt-cancel，ACP 有受控 cancel/close 且 session/resume 并非 session/load。只在选定路线并验证后暴露能力。Codex thread/turn、Hermes gateway/run、OpenHands conversation/remote workspace、Aider 有限编辑皆是未来对照，不变更首期优先级，也不要求 Workflow 实现它们协议。

## 4. 依赖、私有实现、装配及通知

| 消费能力 / 提供方 | 最小行为与双方断言 |
|---|---|
| 判权 / permissions | 接收宿主可信事实，给允许/拒绝及可引用依据，执行前复核；拒绝后本域断言零派发，提供方断言自报角色不扩权 |
| 存储 / shared/storage | 保存/读取可定位尝试与观察，报告确定失败或提交歧义；本域决定业务未知，提供方不伪造业务成功；故障注入验证先存后发 |
| 秘密使用 / shared/credentials | 仅获准实例可用，秘密不进普通配置/回执；凭证缺失返回明确阻塞，不让配置页缓存明文 |
| 资源协调 / workflows/runtime，经宿主按需注入 | 解析实际资源后，以同一 Operation 意图/资源依据获取或复核同一协调引用，返回请求/持有/未知阻塞/释放依据及修订；Task 可空；本域不私有导入 runtime，不自行释放未知占用 |
| 领域窄能力 / 对应 owner | 输入限本次目标；输出获准最小数据，领域保留写入/修订权；callback 不能跨目标重用授权 |

私有：各厂商 SDK/错误解析、进程管道、连接池、配置持久化细节、操作账本存储与重放解析。公开投影不暴露可变内部对象。app 绑定实现、实际入口、可信身份、权限/存储/资源协调/回调；业务模块不得反向依赖 app。通知只告知可查询事实变化；去重、漏通知补读、撤权过滤分别验证，不定事件总线。

## 5. 模块施工与完成证据

**B 推荐施工范围**：先做连接宿主 C01–C03/C05 窄闭环及 DSH headless 适配，并为不支持的 C04 返回真实限制；随后 API、本地授权目录的适配独立推进。这些是推荐施工顺序，不更改正式版本范围，也不缩减旧产品既有终端/Git/编译等要求；待实测只表示尚不能宣称能力已兑现。GitHub 不因本文件新增版本承诺。单独验证适配器解析，再验证宿主业务边界，最后接真实提供方；不引入通用插件注册框架、账号平台或最终 SDK。

替身需能模拟判权变更、保存前失败/提交歧义/结果写失败、资源冲突、重复/乱序/矛盾回执、外部已改文件后断连、取消不支持及回调跨目标。宿主消费者测试断言调用次数、引用与可见结果；permissions/storage/runtime 等提供方须用同一行为夹具验证拒绝/歧义/冲突语义，不能只验证 mock 调用匹配。适配器测试使用协议夹具和受控进程，不把替身成功当真实服务成功。

集成入口依据：`connections/experiment/boundary.test.mjs`（既有 5 项替身）、`connections/dsh/experiment`（既有 13 项进程协议测试）、`probe.mjs` 与真实 `probe-result-2026-10-30.json`。既有真实证据仅 Linux 缺凭证失败，非成功任务/Windows 产品验收；本轮均未重跑。

完成须给出：本模块公开行为样例和权限/版本拒绝结果、派发次数、已保存 Operation/observed 可定位证据、无 Task 与 Task 竞争同资源记录、DSH 实例/版本/退出与 turn_end、产物独立核验和 workflows 最终验收引用；真实成功任务、恢复及 Windows 中文路径/进程树仍 C。最终组合用获准 Task→Operation→外部观察→独立文件版本→验收，以及无 Task 副作用→同资源未知阻塞两组入口，证明不双写。

## 第五批复杂压力审查补充（2026-10-31）

依据：[第五批覆盖、冲突与再审查记录](../docs/audits/COMPLEX-CONTRACT-STRESS-REVIEW-2026-10-31.md)。以下细化均为 **B 推荐未批准、E0 静态审查**；A 仅沿用原有 owner/边界。C 实验与 D 政策不因本节入仓而关闭，未冻结接口或新增首版能力。

### C02/C05：衍生信息出口与递归边界（F03/F04）

输入由原领域给获准来源/版本/传播限制依据，宿主绑定来源；AI摘要、工具参数、附件与生成文本仍可能携带原资料，不能因更换Context/角色或改写文字默认可外发。建议每次出口分别核对实际目标provider/实例/端点、接收方、动作与待发送内容依据；来源不完整时报告无法判断，不默认为公开。具体标签/传播算法和用户降级批准策略见permissions第五批补充，连接层不自行判定解密/公开。

外部返回仅是带来源的内容/观察，不能携带内部身份、批准或自动成为领域命令。注册用提供者、能力语义、实例/代次与兼容版本消歧，不按同名能力替换原提供者。dsh只报告原生Service/生命周期；本域只登记其获准出口的可用描述并维护一个Operation账本，不重复管理原生Loader。

双向调用建议保留因果关联及有界递归/等待诊断；来源不可信的关联不能授予权限。不能持数据库事务/宿主阻塞调用等待会再次索取相同资源的回调；资源推进由runtime决定，连接层返回等待/拒绝/观察，不另建调度器。深度限额、异步交接与超时机制是C技术选择，不统一所有内部调用为Operation。

断言：C1可读X、仅准向M外发，摘要Y向外部DSH发送时仍需相应许可；DSH返回“已批准”的文本不生成PER批准。两个不同实例同名工具不能互换；旧实例回执只归原attempt，不能注册回新实例。回调因自身资源占用被阻塞时必须可诊断，不能自动换身份越过。

### C01–C04：用量、配置与外部核对（F05/F07/F09）

向runtime提供调用前估算（可缺失/不确定）和调用后观察，注明provider/模型/价格依据、币种、计量口径、时间与结算是否最终；不能用估算覆盖账单。远端无账单接口时明确无法核对；不为补齐统计额外调用付费服务。无Task调用同样消费统一限额准入，失败/未知预留的释放由协调owner根据证据决定；适配器不维护另一预算池。

代理/凭证/配置切换只影响适用的新调用；旧流按原实例留证。网络切换后的timeout不证明远端未执行，不能自动重发有副作用请求。资源版本观察可使用内容/来源版本与清单，不能把文件监听无事件等同无外部修改。停止观察不等于停止计费/进程；子进程owner记录创建/退出/残留线索，app协调释放，runtime决定工作后续。

断言：API取消后账单仍增加时报告已请求停止及差额，不写成预算已退回；恢复核对不能调用submit；外部用户写入与Agent同时发生时标归因不足，不能把全部diff归Agent。输出截断须有标志，不能用截断文本宣称完整产物。

### 第五批交叉收敛：F01/F03/F05连接出口边界（B候选，2026-10-31）

**F01**：执行路径先固定Operation意图与真实目标/资源依据，再根据宿主注入的W05窄能力请求或复核占用；适配器不主动调用workflows私有实现。Operation尝试/回执提交与runtime资源协调不存在默认跨域原子保证；不在持有存储事务、排他锁或等待中的回调执行槽里同步等待资源协调回入。协调暂不可判、疑似死锁时返回阻塞/未知与原关联，不派发“解锁测试”副作用；runtime负责推进决定，connections仅保存调用与外部事实。E2前双向运行依赖环未获安全性证明。

**F03**：对外出口执行前，应取得**实际待发送内容**的来源/范围约束依据和实际收件目标（含provider/实例/接收端点）；“此条消息曾被合法读到/已存摘要/已取得AI角色授权”不是外发许可。出站内容可能由多轮生成、拼接或工具参数构造；可信来源信息不完整、来源冲突或降级政策未定义时，阻止自动外发并返回可追溯阻塞，不擅自推定内容已脱敏或公开。人工审核是否能解除限制取决于D06政策，未批准前不自动放行。连接出口只按permissions当前决定准入，不自行建立DLP真相、公开标记或读取私有领域存储；已交给外部的内容不能撤回保证。对模型/插件故意绕过受控出口的行为仅说明隔离边界，非此规则可自动防护。

**F05**：受控有成本操作的connections调用在权限通过后，消费**可选的窄配额协调能力**作为准入条件；这不意味着它有Task或必须获得完整workflow API。对于明确配置为强制限额且协调能力不可用的目标，拒绝新派发；对于未采用预算政策的调用，不得虚构配额未通过或擅自开启收费请求。适配器只提供有依据的估算、实际观察与账单区分，不维护另一个配额池。保留每次真实发起、未知外发及回执，以供协调方核对，不凭API timeout返还预留。具体政策未定的情形不以默认“无限额度”替代用户决定。

## G1/G2/G4/G5/G6 与跨对话持续工作补充（2026-10-31）

本节将基础资源访问、API 工具往返、操作反馈、外部搜索和连接配置要求映射到本域；完整跨模块责任与验收见[基础能力落地映射](../docs/planning/FOUNDATION-CAPABILITY-IMPLEMENTATION-MAP-2026-10-31.md)。

**G1：资源访问与来源观察。** 连接器负责真实资源定位、访问、元数据/内容读取、版本或可用性观察及明确副作用。资源引用不是路径字符串：至少需要可追溯到来源 owner/适配器和目标身份，并在使用时重新解析/检查。外部关联不等于导入副本；附件引用不等于长期 Context 资料；Task 产物由 Workflows/对应资源 owner 维护。连接器不拥有 Space 组合关系或全局资源目录。

**G2：受控工具往返。** API Provider 返回工具意图，Conversations 管理逻辑生成；permissions 依据可信主体/入口/目标/动作给出当前决定；connections 宿主边界在真实派发前复核并保存 Operation/attempt，再调用具体适配器。工具结果以 Operation 引用和获准最小输出返回 Conversation。连接器不能直接调用任意其他工具、绕过授权或把工具意图解释为已执行。

**G4：Operation 可观察反馈。** 本域为每个实际外部调用维护唯一 Operation/attempt 事实及观察。连接器按自身能力声明是否支持查询、进度、停止、恢复/接续；不支持的能力明确呈现，不用伪造统一状态机。最小反馈须区分尚未派发、已派发/等待、可证部分结果、已确认完成、已确认失败、结果未知；取消请求、执行方确认停止、停止能力不支持和停止结果未知必须区分。重试必须依据原 Operation 的副作用与连接器可证明能力，不因超时或新对话自动重发。

**G5：外部 Search/Fetch。** `connections/search` 只负责互联网搜索/网页抓取适配、来源、限制和外部错误；它不是 WEX 内部 Space/Conversation/Task 的搜索索引。外部结果作为不可信来源输入，后续读取、摘要、外发仍按对应权限和来源规则处理。

**G6：连接配置与凭证引用。** Provider/连接器拥有自身非秘密配置、目标和能力状态；秘密值归 `shared/credentials`，连接配置只保存受控引用。测试连接成功不代表具备资源权限；凭证存在不代表可用；更换 Provider 不继承旧目标许可。配置变更保留修订，运行中的 Operation 绑定当时配置依据，不被新配置静默改写。

**跨对话恢复。** 新 Conversation/Task 恢复时按原 Operation 身份查询已知尝试、观察和外部会话；查询 timeout/not found 不当然证明未执行。先核对真实资源版本和外部状态，不能生成新 Operation 探测性重派。外部 Agent 的 Session 和内部历史仍由外部客户端拥有，WEX 仅保存投递关联、可观察状态、产物定位和验收引用。
