# RDA-025｜自建云空间、用户体系与多功能存储创作服务

- 状态：草拟；长期产品方向，未确定部署方式、账号模型或版本计划。

## 1. 需求事实
用户提出过由自己架设、带用户体系的云空间，用于存储、创作及多种功能。它不应被默认理解成单一网盘；需验证 WEX 本地端、用户账号、云端资源与未来创作服务如何组合。

## 2. 场景与参与对象
云服务运营者、用户/主体、账号、设备、客户端安装实例、Space/Context、文件/作品、版本、共享链接、授权、存储目标与同步任务。

## 3. 端到端场景
用户注册或受邀进入自建云服务；通过设备访问自己的空间；创建、存储、版本化和分享作品；授权协作者或 Agent 访问特定资源；账号、设备或服务状态变化时，资源所有权和恢复路径仍清晰。

## 4. 架构压力点
- 账号不等于主体，设备不等于账号，凭证不等于身份，资源不应因账号状态变化而被错误删除。
- 自托管服务、云端存储和 WEX 本地运行时需通过稳定协议解耦。
- 多用户隔离、空间归属、共享、撤权、删除、备份与迁移必须分别定义。
- 资源可包含文件、文本、创作项目、媒体、结构化数据及其他未来类型，不能写死为单一文件目录。
- 用户体系不应成为所有 WEX 本地功能的强制依赖；离线/本地使用边界需明确。
- 云端 Agent 执行与本地 Agent 执行的权限、凭证和回执不可混淆。
- 账号注销、失联、继承、冻结或清除等生命周期状态需要可扩展表达；不在本案例里提前决定具体政策。

## 5. 失败与边界
断网、同步冲突、账号被锁、设备丢失、用户退出/删除、存储损坏、版本回退、共享链接泄露、云服务迁移、服务运营者权限越界。

## 6. 可验证验收条件（候选）
- 同一主体可关联多个账号或设备，关联关系可撤销而不混淆资源所有权。
- 资源拥有稳定身份和版本历史，路径变化或客户端更换不改变资源身份。
- 本地/云端存储由可替换的存储目标接口承载。
- 断网和同步冲突不会静默覆盖不同版本。
- 共享权限与资源所有权分离；撤权不会伪造删除已被复制的外部数据。
- 用户账号系统故障不应自动毁损本地资源或历史回执。
- 云端与本地执行均能明确标识执行主体、运行位置、授权来源和结果状态。

## 7. 待决问题
自建服务是个人单租户还是未来多用户服务、是否公开注册、云端与本地的权威数据关系、加密与备份、计费、创作功能清单、运营者权限和部署成本均未确认。
