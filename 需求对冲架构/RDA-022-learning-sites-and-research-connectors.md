# RDA-022｜学习网站与研究资源接入

- 状态：草拟；历史需求方向，尚未冻结产品范围。

## 1. 需求事实
WEX 曾考虑接入学习网站、教程、课程或其他在线研究资源。目标是把它们作为研究和学习工作流中的外部来源，而非为每个网站写入核心专用逻辑。

## 2. 场景与参与对象
用户、学习/研究 Context、Agent、网站连接器、课程/页面/文档资源、来源引用、笔记与研究成果。

## 3. 端到端场景
用户指定学习目标；WEX 通过获授权的连接或用户提供的资料获取内容；Agent 将内容与来源关联，形成笔记、进度或研究产物；产物可保存到 Context 或指定输出目标。

## 4. 架构压力点
- 网站访问、搜索、下载、登录、进度追踪是不同能力，不应假设一个连接全部支持。
- 来源内容、Agent 总结、用户确认结论必须区分。
- 同一资料可能被个人学习、工作研究和公开项目引用，但各 Context 的可见性不同。
- 连接器可能受网站条款、认证、反自动化机制和内容版权限制。
- 学习进度属于用户或学习项目状态，不应与知识条目混存。

## 5. 失败与边界
登录失效、页面结构变化、付费内容不可访问、重复采集、来源 URL 失效、内容更新、摘要错误、下载不完整。

## 6. 可验证验收条件（候选）
- 新增一个学习资源适配器不要求修改核心 Context 或调度模型。
- 每条研究结论可追溯到来源和采集时间。
- 原始资料、摘要、个人笔记和已验证知识分层保存。
- 无授权或不支持的站点能力明确拒绝，不伪造采集成功。
- 输出可选择保存到本地、项目 Context 或后续获准的存储目标。

## 7. 待决问题
具体网站、课程管理、学习进度同步、浏览器自动化及版本优先级待确认。
