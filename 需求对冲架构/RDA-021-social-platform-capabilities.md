# RDA-021｜社交平台与跨平台内容能力

- 状态：草拟；用户重新提出的历史需求，尚未冻结产品范围。
- 类型：需求压力案例，不预设具体平台或实现。

## 1. 需求事实
WEX 的长期方向曾包含社交平台相关能力。需要检验系统能否将外部社交平台视为可组合的连接与能力来源，而不是把某个平台写死为核心模块。

## 2. 场景与参与对象
用户、角色 Agent、社交平台账号、连接实例、内容资源、媒体附件、发布/读取能力、授权与回执。

## 3. 端到端场景
用户授权连接某个平台；WEX 发现该连接提供的读取、发布或管理能力；Agent 在指定 Context 和权限下执行；返回可追溯的结果和外部资源引用。

## 4. 架构压力点
- 一个连接提供多种能力，不应将连接、账号、能力和资源混为一体。
- 不同平台支持的读取/发布/媒体格式/速率限制并不一致。
- 账号断开、Token 失效或权限撤回后，历史内容引用和操作回执仍应可追溯。
- 私人、工作、公开项目的内容与授权范围不能因 UI 分类自动互通。
- 社交平台内容可作为不可信输入，不能自动成为公共策略库中的可信结论。

## 5. 失败与边界
授权失效、API 限流、重复发布、部分媒体上传成功、平台内容删除、回执丢失、外部操作结果未知、跨平台内容语义不一致。

## 6. 可验证验收条件（候选）
- 新增平台适配器不要求修改核心调度器的业务分支。
- 连接身份、外部账号身份、能力 ID、资源 ID 和操作 ID 可分别追踪。
- 不同平台的能力差异通过声明与结果类型表达。
- 撤权阻止新操作，但不会伪造删除已发生的外部事实。
- 外部内容导入与公共策略库入库之间存在明确的审查/来源边界。

## 7. 待决问题
具体平台、是否支持主动发布、自动化程度、媒体存储策略和当前版本范围均未确认。
