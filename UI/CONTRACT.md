# UI 交互契约草案

第四批仅文档；基线 `owla19s-ux/WEXPC1@a62996af9863e60b15e4513389c7654719907920`。公开动作是面向用户的业务交互描述，不冻结组件、TS类型、IPC或状态枚举。

## 边界与证据

UI owner 是导航、页面/公共控件、临时输入/选择、动作反馈与模块面板挂载；非 owner 是 Context、消息、Task、操作回执、授权和验收真相。renderer 通过可信宿主装配的窄桥查询/提交，不能直接导入 Node 领域实现、文件系统、凭证或深读私有状态。UI 按实际页面组织，模块专属面板随模块。

依据：UI/README、根 README、研究决策 §6–9、全局契约地图、功能全景、views审计及 editor App/model/验证报告。原型选中状态不持久化、先保存再提交和失败反馈是可借鉴的历史证据；原型无权限/宿主桥，不能直接升级为安全产品页面。本基线 UI 只有说明，未实现本契约。

## 公开动作与交互结果

所有动作的可信主体由宿主确认；页面参数/模型输出不提供授权。Context 是可空选择，Task 不作为普通聊天前提。控件可用性只是帮助，实际边界再次校验。对无权对象和不存在对象展示同等不可用，不泄漏标题、数量、搜索匹配、历史残影或错误中的定位。

全部保存/提交反馈区分**确定未提交、确认提交、提交未知**（证据语义，不冻结状态枚举）。仅owner证明未提交才能显示未保存；ACK或原业务关联回读确认后显示已保存。ACK丢失/超时显示待核对，保存原关联并回读，不重写、不补偿删改，不把暂查不到或按钮取消当未提交证明。原型同步localStorage失败不推进修订不能外推为异步提交失败必然未落盘。

| 动作、目的与消费者 | 前提、调用与可见证据 | 失败、恢复、并发与具体断言 |
|---|---|---|
| 导航/打开页面/挂载面板：用户进入聊天、Space、配置及专业页 | 路由选择只改变交互位置；桥返回获准模块/数据；每页显示加载依据与未完成动作。模块未就绪明确说明，不假装空白成功 | 页面查询超时/断线显示不可用或过期；取消导航请求不停止任务/生成。旧页响应不得写入新页；重开回读领域。断言：关闭任务图后工作继续；缺失工作盘不显示“空的新工作区” |

| 选择背景/资源/角色/连接：用户配置本次工作 | 仅提交相应 owner 的关系变更，明确选择不等于可读、可发送、获权执行；实际派发显示所用背景/连接依据。密钥只经凭证路径写入，不回显明文 | 目标失联/撤权清除敏感展示且禁止旧缓存打开；拒绝信息不泄漏是否存在。并发配置变更按 owner 修订提示重读。断言：选择角色/Context后运行仍可能被权限边界拒绝，UI不显示已授权 |

| 采纳草案/创建Task/启动/暂停或取消工作：用户明确推进 | 分别调用 conversations/workflows/连接边界授权路径；呈现目标/范围/验收、当次授权与回执依据。任务创建、启动获准、外部已执行、已核验、最终验收分别反馈 | 超时/断连显示未知，按原关联查询；不以按钮已点/退出0/AI自报显示完成。取消请求不宣称回滚。断言：创建 Task不自动启动；外部完成但验收缺失时UI不能显示验收通过 |

| 设置/诊断/恢复：用户检查配置和重启续接 | UI挂载模块面板，owner保存配置；诊断脱敏并标明事实来源/时间；恢复读取原会话/任务/attempt关联，不用重发代替。正常重启/普通升级重新核对现有凭证可用性、当前授权、格式兼容及在途证据；卸载重装/系统重装进入重新接入资料、重配凭证与授权流程，即使旧凭证仍可解密也不得直接复用为有效许可 | 确定未提交不显示成功；提交未知待核对；缺盘/凭证/连接分别报告。重装保留的历史批准只供审计，旧Task不自动续跑；普通重启/升级也不得凭历史批准跳过当前检查或重派未知工作。退出协调交app。断言：系统重装接回旧资料且可解密旧Key，UI仍要求重配凭证授权，旧任务停留待核对；诊断不含密钥 |

## 最小依赖、私有实现与装配

UI只需要领域桥提供获准查询、受控动作、提交关联/修订及可回读结果；conversations 提供生成/消息依据，space提供组织关系，views提供布局/投影，workflows提供工作事实，permissions提供授权反馈，connections提供就绪/操作证据摘要，app提供生命周期/导航装配。桥负责来源识别、鉴权接点与参数边界，领域继续检查业务规则；UI不因桥已检查而拥有领域写权。

临时焦点、未提交输入、选择、弹层及请求取消控制为UI私有；长期消息/布局/设置依对应owner保存。通知可重复/缺失/重排，带来源依据回读；离页取消订阅和释放图形资源。模块通知不是跨域写指令。施工按实际页面在 UI/conversation、UI/settings等就近增添必要实现与测试，不建立全局业务 store 复制所有领域状态；专业面板随模块，主UI负责挂载。

## 双方替身、组合验收与完成证据

UI消费者替身必须能返回保存失败、响应丢失但已提交、未知副作用、晚到旧修订、无权与不存在等价不可用；用表中样例断言控件/反馈不造成功。各领域提供方用相同样例验证桥后真实语义，不能只检查字段结构。桥替身禁止直接写领域内存；桥提供方测试检查宿主身份、目标授权、拒绝不取数及renderer不能接触密钥。

组合最小验收：普通聊天无 Context/Task；发送中换页/重开；确定未提交与提交ACK丢失分别注入，后者一次提交、回读核对且无补偿删改；跨窗口冲突；撤权后多页缓存；创建/启动/核验分步；未知操作恢复无重派；正常重启/普通升级与卸载重装/系统重装分别验证，重装可解密旧凭证仍须重配授权且旧任务不自动续跑。再做真实浏览器鼠标拖拽/连线、键盘/焦点及Windows Electron窗口生命周期；jsdom/HTTP不代替这些证据。完成记录须有基线、环境、命令、用户可见截图/结果、持久回读及未覆盖项。本批未运行产品/测试/Actions。

### 恢复、交接、通知与全局检索（F02/F05/F07/F09）

运行中的定义编辑应明确作用于后续启动还是申请迁移；未实现迁移时只允许新版本编辑并标明旧运行依据。删除节点/清除卡片不宣称停止外部工作。恢复入口先显示核对进展及原关联，只有owner完成当前检查才呈现可继续动作；按钮双击/通知点击不能触发隐式submit。

交接反馈分开旧执行停止证据、新负责人、新轮次和剩余目标；预算显示估算/预留/观察/真实结算来源差异、币种和时点，不显示未经证明的硬封顶。预算用尽、连接不可用、权限拒绝分别给实际owner的修复入口，不以一键重试绕过未知。

通知来自领域获准事件，UI/app仅呈现最小线索/导航；点击后重新查当前权限/状态，旧通知不完成验收。搜索聚合领域当前获准查询，说明掉盘/未建索引等不完整范围；相同Context多处放置区分本体与位置，不重复算两份内容。未批准前不启用后台常驻/自动更新/敏感通知预览。系统休眠/代理变化显示旧观察时点，不能把网络恢复等同任务成功。

断言：通知生成后撤权，点击不出现原敏感标题；搜索部分提供方失联不显示“全库无结果”；恢复点击到完成核对期间submit为0；修改预算不使已有unknown回执变为已取消。Windows键盘/焦点/高DPI、剪贴板/拖放路径、OS通知隐私与窗口退出为E4待验。
