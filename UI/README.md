## 基础桌面交互补充（2026-10-31；候选目录，尚未实现）

依据[源码目录 §12](../docs/WEXPC-SOURCE-LAYOUT-AND-WINDOWS-DATA-2026-10-30.md#12-基础能力补充后的代码目录归并2026-10-31-审查建议尚未创建源码子目录)与[基础能力缺口清单](../docs/research/APP-FOUNDATIONS-GAP-AUDIT-2026-10-31.md)，在现有页面与模块面板挂载原则下，将通知呈现/历史入口候选归于`notifications/`，跨模块搜索/跳转交互候选归于`search/`。二者**尚未创建且无需提前建立**，简单交互可直接写在使用它的实际页面。设置页负责挂载各模块自身配置、诊断、日志浏览/导出入口，不能因此接管底层配置或审计权威。

通知/搜索必须经领域公开的获准查询构建结果，不能绕过权限或把缓存当最新业务事实；撤权、目标失联、旧通知跳转及旧搜索结果须重新校验来源。主UI只保存临时焦点与交互，不维护第二套Task、Operation、许可、连接状态。Windows菜单、系统托盘、快捷键和拖放按app平台接线与UI实际交互协作，不为每种原生功能建独立目录；高DPI/键盘/无障碍支持随真实窗口验收。

验收需检查通知误报、无权搜索泄漏、跨窗口过期结果、旧缓存、消息/日志导出脱敏及程序未配置完整时的可用性；目前只有设计，没有桌面成品。
