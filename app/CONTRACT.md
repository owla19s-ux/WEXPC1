## 依据、等级与 owner

固定依据：WEXPC1 `a62996af9863e60b15e4513389c7654719907920` 的 README、`app/README.md`、`shared/{README,storage/README,credentials/README}.md`、`docs/decisions/RESEARCH-DECISIONS-2026-10-30.md`、`docs/architecture/GLOBAL-CONTRACT-MAP-V0.1.md`、`docs/research/{WINDOWS-LIFECYCLE,SECURITY-AND-PERSISTENCE}-2026-10-31.md`；重装规范来自旧 wexpc `faf11f31d44e4fc4788e766074b8db6b83ab4a1b` `docs/PC-PRODUCT-AND-TECH-BASELINE.md` §5.6。研究文件内的其他 SHA 是历史来源，不改变本次读取基线。

- **A 已定**：TypeScript + Electron + React 路线；app 为可信装配根，负责启动、窗口/宿主进程与退出协调；业务模块不反向依赖 app；目录与业务权威分开；正常重启和重装分别处理；重装不得静默恢复凭证/有效授权。
- **B 建议未批**：下列能力划分、样例、启动隔离和恢复屏障是本批可审查的语义建议，尚非用户批准接口。
- **C 实验**：bootstrap profile、安装身份识别、退出中断、Windows 限权、迁移、安装器/maker、升级身份、路径保护与真实打包均须实验。
- **D 决策**：后台运行、关闭窗口、显式清理的交互/范围、目录迁移的用户行为及取消/强杀的产品策略尚待决策；其实现机制列 C 技术验证。Electron 已定；Forge 仅候选，不能写成最终打包器。

owner：app 维护装配关系、宿主/窗口生命周期、平台路径接线与可用性诊断；各领域维护自身恢复、授权、任务和业务数据。下列 APP-* 仅是**文档能力 ID**，不是函数名、事件名、IPC 名或 ABI；不冻结库、schema、Windows IPC 或取消协议。

## APP-01 数据根定位与安全接入

**目的/消费者**：让用户选安装与数据位置并重新找到既有资料；UI 启动页、shared、所有领域初始化消费已核验的定位结果。安装目录、公共数据根、Space 工作区、独立 Context、外部资料分开；改 Space 放置不搬文件。

**前提/入口**：平台启动或明确用户选择；可信宿主建立本机使用关系，路径字符串、目录名、Context 自报值均不能证明身份或授权。Context 可空（全应用定位），有 Context 时仅定位其登记，不取得其资料访问权。资源是根、profile、索引及目标目录；目录/ACL 检查是技术前提，业务读取另由 owner 与 permissions 判定。

**写入/证据**：只维护最小定位信息与接入诊断；公共登记只定位，不成为第二份 Context/Task 真相。记录所选根、检查结果、适用版本和定位修订，禁止记录秘密。小型系统定位文件是 B 候选例外，须列实际写入位置；丢失后可浏览识别旧根。Chromium sessionData 必须在 ready 前确定；首次选根需验证 bootstrap/重启路径，不能 ready 后改路径冒充完成。

**拒绝与恢复**：缺盘、只读、ACL 拒绝、格式不兼容、身份冲突分别报告；不自动新建同名空库覆盖旧引用。扫描超时/断连仅能断言“未完成检查”，不能断言目录不存在。取消选择保持旧定位；重复确认同一根不重复初始化；重试先复核目录身份与修订。并发重定位/迁移必须排他或拒绝，算法未定；缓存检查过期不能覆盖新选择。

**具体断言**：原根 E: 掉线后启动，应显示其失联及受影响能力，旧 Context 引用仍在，C: 不出现替代空项目；E: 恢复后复核原身份再接入。两个窗口同时选择不同根，旧修订提交被拒绝，不能各模块分别写向两个根。带中文/空格路径可定位；网络盘支持尚无结论，不能按本地 NTFS 宣称可写。

## APP-02 可信装配与能力可用性

**目的/消费者**：为 UI 与领域接入最小公开能力，局部故障能诊断。前提是提供方就绪、版本兼容和必要平台机制可用；由可信宿主注入真实 permissions、storage、credentials、runtime 协调及领域窄回调。Context 可空；非 Task 对话/单次调用也装配同一受控外部边界与资源冲突检查。

**主体/资源/权限**：Renderer、插件和外部 Agent 的自报身份不可信；不能取得 app 容器、可变数据库、完整 Context 或万能宿主对象。入口能力的调用权归 permissions，装配成功/能力发现/凭证存在都不授予调用权。内置连接器可直接装配，不以 plugins 或 Cordis 为前置。

**权威/证据**：app 写就绪/降级诊断及装配版本，不能写 Task/Operation 最终状态。第三方插件不得加载进 Electron 主进程；DSH 独立宿主与外部 DSH Agent 连接器分开。独立进程只是故障隔离起点，令牌、环境、文件、网络、凭证与子进程可达性待实测，不是安全保证。

**失败/重试/并发**：缺提供方、初始化失败、超时各自标识不可用及影响范围，不伪造成功数据；已启动一半时释放已持有资源，但不擅自撤销外部副作用。装配取消与完成竞态以宿主世代/注册归属核对（B）；过期回调不得重新注册已卸载能力。重试只初始化失败项且不得重复安装处理器；确切取消语义 D。

**具体断言**：credentials 不可用时仅相关连接显示凭证不可用，本地可见组织仍能读取；连接器请求完整数据库必须无此出口；插件声称 Context=X 不得改变注入主体。非 Task 文件写入与 Task 写同 Git 工作区时，均到 runtime 同一冲突检查。外部模块初始化超时后迟到 ready 不得覆盖当前已停用状态。

## APP-03 窗口、退出与中断恢复协调

**目的/消费者**：UI、workflows/runtime、connections 与 storage 在退出/崩溃/重启后能解释工作事实。可信宿主发起生命周期协调，Context 可空或多 Context；资源包含窗口、进程、未决操作及存储连接，具体领域状态由 owner 写。

**前提/权限/证据**：关闭图或切换 Context 不自动取消任务。退出请求只能向提供方发保存/协调请求，不能把窗口销毁、IPC 断开、停止等待或进程退出解释为外部停止、成功、回滚。正常退出记录各参与方确认及未决定位；系统关机/强杀不保证退出钩子运行，关键事实需此前持续提交。

**结果与恢复**：保存拒绝/失败、协调超时、外部断连分别呈现，事实不充分为 unknown。停止等待、请求取消、确认终止各自留证，取消协议不冻结；没有确认不得释放未知冲突范围。重启让 workflows 决定工作恢复、connections 核对原 attempt，app 不重派。重复退出请求去重协调会话；新旧宿主/迟到回调按运行世代隔离，旧回执交 owner 核对，不覆盖新轮次。用户取消退出后是否恢复排队/监听由协议决定，不推断已取消外部执行。

**具体断言**：关闭运行图后外部操作关联仍存在；杀宿主于外部修改后、回执保存前，重启显示待核对且不自动再次执行；连接断开后即使窗口成功关闭也不得显示任务已取消。模拟 storage flush 超时，诊断保留哪个 owner 未确认；不能仅用 app 的“退出完成”证明持久化成功。普通重启在原有效关系内接续，不强制每次重填 Key。

## APP-04 安装、升级、重装接回

**目的/消费者**：用户保留项目/会话/任务/证据、插件和环境文件，同时不继承重装前访问权；UI 恢复入口、各领域和 credentials/permissions 消费区分后的生命周期证据。Context 可空；接回单 Context 也不能绕过本机使用关系判定。

**前提/主体/资源**：可信宿主核对安装/数据版本与使用关系；路径相同、同名 Windows 用户、可解密 blob 均不足。普通升级、正常重启、卸载重装、Windows 重装分别识别并留证，识别机制未选定，无法确认时不按正常重启静默恢复敏感能力。

**写入/权限**：app 只协调接入屏障与兼容诊断；各域恢复资料，credentials 要用户重新配置，permissions 要重新授权。历史批准/全局开关/执行策略仅供审计，未完成任务可见但不自动续跑。插件文件可复用不等于启用/执行初始化；环境可检查复用不授予脚本执行权。普通目录迁移不一律吊销凭证，普通升级不得冒充重启绕过重装边界。

**失败/取消/修订**：迁移前一致备份与停写/切换屏障是 B 建议；版本不兼容拒绝写入或明确只读，不清空；跨文件迁移中断按阶段核对，不假设原子。超时/掉盘保持原数据及未决标记；取消不得自动删除半成品与原件。重复恢复先检查已迁移版本、根身份和当前 owner 修订；旧程序不可写新格式。安装程序与数据 root 混放需阻止或保护，保护机制列 C。默认卸载保留数据已定，仅移除程序与系统集成；显式普通数据清理的 UI 与范围仍待决定；无论实现何种清理，外部引用不可递归删。

**具体断言**：卸载重装且旧 Windows 凭证仍可解密，选回原根后会话可见，但连接不可静默使用旧 Key，旧批准不派发；重新配置并重新授权后再核对未知操作。正常重启对照样例不要求重配；升级迁移失败后原库仍可恢复，降级程序明确不兼容。保留插件缺依赖时显示需修复，不自动执行其脚本。

## 依赖最小行为、私有装配与通知

| 提供方 | app 所需的最小可观察行为 | 禁止假设 |
|---|---|---|
| shared/storage | 根/格式诊断、技术读写/提交结果、关闭/备份状态 | 超时就是未写入；备份涵盖外部资料 |
| credentials / permissions | 可用性、使用关系失效与重配/重授状态；真实授权入口 | 持有秘密等于获权；app 自造权限账本 |
| 各领域 | 初始化/恢复/暂停接入及未决诊断，自己维护业务修订 | app 能改业务状态或恢复全部为 ready |
| connections / runtime | 原操作定位、unknown、冲突范围及恢复协调结果 | 进程死等于远端停；无 Task 无需协调 |
| 平台/安装适配 | 生命周期观察、路径/ACL/进程可达性与版本证据 | Electron sandbox 能约束任意 Node 插件 |

私有实现包括启动时序、依赖创建/释放顺序、profile bootstrap、窗口创建、进程适配、安装标识与诊断接线；不要求业务调用都过 IPC。就绪/不可用/路径失联/退出请求可作内部通知，通知只提示消费者重新读取公开事实，丢失或重复通知不能改变业务真相；通知协议仍待实现契约。

## 替身、集成入口与完成标准

施工范围：本模块后续仅实现启动/路径接线、窄能力装配、生命周期及恢复屏障与平台适配；不在 app 实现领域状态机、授权引擎、连接器业务、主 UI 布局或插件市场。通信边界另见 [COMMUNICATION.md](COMMUNICATION.md)；本文件的主体可信性、最小暴露、unknown 与生命周期约束不依赖该附文才成立。

app 消费方替身须可注入根掉线、旧版本、初始化迟到、flush unknown、停止未确认、旧安装可解密凭证；断言 APP-01..04 的拒绝、诊断与零重派。真实提供方再运行同一输入/可观察结果样例，证明替身未把“停止/保存”简化为总成功；提供方给出其结果证据，app 给出正确接线证据，双方均须过。

当前没有产品启动入口。未来集成入口由 app 实现者在本文件补充实际路径/命令；不得虚构 main.ts 或 package script。首个真实组合应为 app + storage + credentials/permissions + 一个领域恢复提供方，再加入 connections/runtime 故障样例；Windows 安装/重装、双用户 ACL、中文路径、缺盘、强杀/关机、升级回退与进程树退出须真机留证。单模块 mock 通过不算组合通过。

完成标准：每个 ID 的具体断言有 owner/消费者共同结果；记录实际命令、平台、版本、证据与未覆盖项；公开出口无容器/数据库/秘密泄漏，领域不导入 app；正常重启、卸载重装、系统重装、升级四类分别验证。准备度：**仅语义草案可审查，未获实现契约冻结，未实现/未运行验收**。阻断缺口是安装关系识别、首次 profile 时序、后台/关闭策略、取消确认、跨域恢复/迁移屏障、Windows 真机及 OS 限权证据。

### APP-01–04：基础设施交错与恢复屏障（F08/F09）

建议区分同用户重复启动协调、数据根写入占有、业务资源协调三层：app维护实例/宿主生命周期，shared提供实际根身份/锁证据，runtime维护工作资源。Electron单实例不能证明两个Windows用户或两份安装不能同时写同根。检测旧锁/旧进程须基于身份/代次与实际活性，不凭超时删锁；无法证实安全写入时仅开放获准诊断，不静默创建第二根。锁与ACL机制为C。

启动/崩溃安全模式只隔离可疑宿主并报告受影响能力；不删除插件数据、抹除未知Operation或恢复已撤许可。更新应用、迁移数据、升级原生插件、切换连接实例分别协调，各owner确认兼容/未决事实；回滚程序不回滚远端副作用。睡眠恢复与代理切换后先使健康观察过期，由owner核对在途，不一键重派；普通重启是否继续仍遵守D04，不暗定后台常驻。

通用网络偏好与配置代次由app装配，连接器决定自身支持和请求级证据；不得改变不支持代理的连接后显示全局“已连接”。通知只投递获准最小线索，点击交UI按当前可见性查询；不能用系统通知内容长期缓存敏感标题。全局搜索由UI聚合领域获准结果，app不建另一内容owner。

断言：第二Windows用户打开同根不能仅因Electron锁未冲突取得写权；崩溃后安全启动无新外部submit；睡眠中完成的旧任务通知点击不得验收当前新产物；更新失败保留旧数据与原操作定位，不自动重放。平台例外、启动诊断落盘位置需用户可检查，仍遵守选择数据根要求。

## 第七批实际实现（2026-10-31）

当前公开入口 `app/src/index.ts`；`assemble` 只消费可信内置模块定义，不加载第三方代码。先检查重复ID与依赖环，再拓扑装配，仅注入声明的依赖窄面，冻结依赖映射；不公开全容器或DB。缺依赖、依赖不可用、初始化失败与超时分别诊断。必需能力失败为failed；可选能力失效为degraded；装配不产生业务授权。

生命周期以一次stop协调，逆序释放已注册资源；超时结果不允许迟到注册，迟到实例仍需stop。初始化或释放尚未确认时返回incomplete，清理失败保留诊断，不报告外部已停止；迟到成功释放后允许重新确认stop。初始化函数在返回实例前自行清理其部分资源，AbortSignal只请求停止，不能保证平台工作已停。

`startFoundations` 实际核验已存在数据根、取得 RootLock、装配真实shared技术存储与permissions，再向受信任宿主暴露明确的权限能力。权限聚合位于用户所选根 `permissions.sqlite`；app只接线，不解释/维护其业务数据。数据库及journal/wal/shm既存符号链接拒绝；无法确认关闭时保留根锁。路径检查不承诺对抗同用户恶意并发换链，Windows句柄/重解析点/ACL仍C。

`app/src/main.ts` 是可执行无窗口诊断入口：`npm run start:headless -- <已有根目录>`。根需预先由可信维护者创建 `.wex-root.json`，例如 `{"format":1,"id":"chosen-root"}`；本批没有安装/选根向导，不在缺根时生成替代数据。CLI不授予任何权限，退出只释放宿主资源，不创建/取消Task。

该入口验证基础装配，不是Electron应用或完整WEX闭环。没有Electron窗口、preload/IPC、React UI、后台常驻、开机启动或窗口关闭策略；未对这些未来接口建空实现。Electron/Windows接线及E4仍未验证，不冻结打包器/平台协议。D04与全部D01–D07未代裁。

测试：`npm run test:app`。提供方生命周期测试使用故障模块；消费方同一权限reader向量对照真实与替身；集成真实根/锁/SQLite/permissions，覆盖撤销持久化、缺模块/存储、链接逃逸和不确定释放。

## 第七批收尾修复（2026-10-31）

app/src/assembly.ts 对未确认释放的模块实例保留引用；stop 返回 incomplete 后允许再次调用，重试失败实例和迟到初始化实例的清理。成功释放的实例才从待清理集合移除，历史 release_failed 诊断保留。startFoundations 外层仅缓存进行中的stop；provider关闭或root lease释放未确认时清除缓存，下一次stop重新执行必要步骤。root lease 仅在所有provider停止确认后释放。相关行为由 app host 与真实SQLite集成测试覆盖。
